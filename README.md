# Airway Lab — אתר לימוד לנתיב אוויר

אתר לימוד סטטי בעברית, RTL, מותאם לנייד ול-GitHub Pages. אין צורך בשרת, בבסיס נתונים, ב-API או במפתח חיצוני.

## מה כלול

- 7 נושאי לימוד עם 85 כרטיסיות ו-47 שאלות מבחן: סמכויות, פתיחת נתיב אוויר ו-OPA, חמצן וסטורציה, אינטובציה וציוד, תרופות וסדציה, LMA, קפנוגרפיה ו-CO₂.
- כרטיסיות שליפה עם חזרות קצרות למבחן של מחר: 3 דקות (לא ידעתי), 15 דקות (בערך), ואז 45 דקות, 90 דקות, 3, 6 או 10 שעות (ידעתי). אין תזמון לימים קדימה.
- במעבר לגרסה זו, מועדי חזרה עתידיים שנשמרו מהגרסה הקודמת מאופסים פעם אחת כדי שכל הכרטיסיות יהיו זמינות ללמידה לקראת המבחן.
- מבחנים אקראיים של 10, 20 או כל השאלות, עם משוב והסברים.
- דפי סיכום וחיפוש בחומר.
- דף נתונים לשינון הכולל מספרים, הגדרות ואלגוריתמים כפי שמופיעים בסיכום המקורי שסופק.
- שמירת התקדמות מקומית בדפדפן באמצעות `localStorage`.
- PWA בסיסית: ניתן להתקין במסך הבית ולשמור את קובצי האתר לשימוש חוזר לאחר טעינה ראשונה (דרך HTTPS).
- מצב כהה. אין תלות בשירות חיצוני או בגופן מרוחק.

## פרסום ב-GitHub Pages

1. צרי Repository חדש ב-GitHub.
2. העלי את כל הקבצים והתיקיות שבחבילה הזאת ל-root של ה-Repository (לא להעלות רק את `index.html`).
3. פתחי **Settings → Pages**.
4. תחת **Build and deployment**, בחרי **Deploy from a branch**.
5. בחרי את `main` ואת `/(root)`, ואז **Save**.
6. אחרי ש-GitHub Pages יסיים לפרסם, פתחי את כתובת האתר שנוצרה.

אפשר גם להעלות את הקבצים לתיקיית `/docs` ולבחור אותה ב-GitHub Pages, אבל במקרה כזה יש להעלות את כל הקבצים יחד לאותה תיקייה.

## שימוש בנייד

פתחי את כתובת GitHub Pages ב-Chrome או בדפדפן תומך, ובחרי בתפריט הדפדפן **Add to Home screen / התקנה**. ההתקנה והעבודה הלא-מקוונת תלויות בדפדפן ובתמיכתו ב-PWA. בפעם הראשונה יש לפתוח את האתר עם חיבור לרשת.

## פרטיות ושמירת נתונים

ההתקדמות נשמרת רק באחסון המקומי של הדפדפן במכשיר שבו משתמשים. ניקוי נתוני האתר/הדפדפן או מעבר למכשיר אחר עלולים למחוק או לא להעביר את ההתקדמות. כפתור **איפוס התקדמות** מוחק את ההתקדמות המקומית.

## התאמת חומר הלימוד

תוכן הלמידה ודף הנתונים מבוססים על הסיכום שסופק בשיחה. דף הנתונים כולל גם את המספרים והמינונים כפי שהופיעו במקור, לצורכי הכנה למבחן בלבד.

האפליקציה היא כלי לימוד למבחן בלבד ואינה הנחיה לביצוע טיפול. בפרקטיקה קלינית יש לפעול לפי הכשרה, מדריך/ה והפרוטוקול התקף של הארגון.

## מבנה קבצים

- `index.html` — מבנה האתר.
- `styles.css` — עיצוב רספונסיבי ו-RTL.
- `app.js` — תוכן לימוד, שאלות, כרטיסיות, חזרות ושמירת התקדמות.
- `manifest.webmanifest` — פרטי אפליקציה להתקנה.
- `sw.js` — מטמון בסיסי לשימוש חוזר/לא מקוון.
- `icon.svg`, `icon-192.png`, `icon-512.png` — סמלי האתר.

## הערת למידה

המערכת משתמשת בשליפה פעילה ובחזרות מרווחות, אסטרטגיות הנתמכות במחקר בחינוך מקצועות הבריאות. הן עשויות לשפר זכירה וביצוע, אך אינן מבטיחות זכירה של 100% או ציון מסוים.
